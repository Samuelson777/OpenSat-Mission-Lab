Capabilities

Space engineering, data systems and operational assurance.

OpenSat Mission Lab grew from a two-body orbital demonstrator into a broad mission-engineering portfolio. Every capability remains inspectable and runnable on a home PC.

A

Astrodynamics

Two-body and J2 propagation, eclipse analysis, coordinate transforms, ground access, external comparison adapters and analytical benchmarks.

P

Payload operations

Camera footprint, target visibility, priority-aware imaging, data generation, storage, compression, cloud filtering and scheduling.

E

Electrical power

Solar generation, battery integration, mode-specific loads, eclipse discharge, safe-mode entry and hysteretic recovery.

C

Communications

S-band link budgets, C/N₀ and Eb/N₀, adaptive data rates, pass capacity and actual onboard-storage depletion.

D

ADCS

Quaternion kinematics, sensor noise, detumbling, pointing modes, wheel momentum and magnetic unloading.

F

Flight software

Mode logic, commands, telemetry, CRC packets, watchdog reset, limit monitoring, deterministic fault injection and recovery.

EO

Earth observation

GeoTIFF ingestion, spectral indices, ground-truth metrics, temporal optical/SAR fusion and flood progression.

AI

Onboard autonomy

Explainable event scoring, resource-aware keep/discard decisions, target reprioritization and autonomous task planning.

CS

Constellation safety

Walker-style formations, crosslinks, shared ground resources, conjunction screening, maneuver trades and replanning.

API

Service platform

REST/STAC APIs, workers, object storage, database catalogues, backups, role controls and deployment assets.

S

Security & resilience

Zero-trust controls, SBOMs, signed evidence, observability, chaos exercises, active-active routing and governance.

✓

Safety assurance

Signed approvals, dual control, exact command authorization, workflow migration, replay and finite-state checking.
